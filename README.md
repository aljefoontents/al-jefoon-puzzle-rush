# Al Jefoon Tents - Sliding Puzzle

GitHub Pages-ready standalone sliding puzzle.

- 4x4 puzzle: 15 vector tiles + empty slot
- Built-in inline SVG vector artwork only
- Mouse hold/drag
- Mobile touch drag
- Tap-to-slide fallback
- Solvable shuffle
- Timer, moves, coins
- Store and achievements
- How To Play
- Back buttons
- No Event section
- No external image URLs or libraries

Upload index.html, style.css and game.js to the same GitHub Pages folder.
